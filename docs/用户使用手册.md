# 智慧低空应急运输教学平台 · 用户使用手册

> 版本：2026-09 ｜ 适用对象：教师用户、学生用户

平台以"灾情应急物资低空运输"为教学情境，将 **AI 智能体** 引入课堂：学生在四步向导中完成从灾情建模、物资分配、无人机选型到路径规划、AI 辩论、方案优出的完整决策链；教师通过智评大屏、方案审阅和教学监控掌握全班学情。

***

## 一、快速开始

### 1.1 登录

打开平台首页 → 输入账号密码 → 点击登录。

- **教师账号**：由管理员/部署者开通
- **学生账号**：自行注册（见 1.2）

### 1.2 学生注册

登录页点击"学生注册"，填写：

| 字段      | 说明                    |
| ------- | --------------------- |
| 姓名      | 真实姓名                  |
| 学号      | 唯一标识，登录账号             |
| 班级 / 小组 | 选填，用于大屏分组统计           |
| 教师邀请码   | 选填，向指导老师索取，填写后归入该教师名下 |
| 密码      | 两次输入一致                |

注册后返回登录页用学号登录即可。

> 提示：教师可在「系统管理 → 学生管理」页右上角查看/复制邀请码；平台只有一位教师时，不填邀请码也会自动归属该教师。

### 1.3 首页

登录后进入首页，点击中间三张卡片进入对应智能体：

| 卡片       | 说明                           |
| -------- | ---------------------------- |
| **应急调度** | 核心教学模块：灾情案例 → 路径规划 → 方案优出全流程 |
| **装箱评价** | AI 视觉评价运输箱装载规范性，实时评分         |
| **课程图谱** | 浏览课程知识图谱与项目详情                |

页面底部"数据总览"可展开查看平台运行数据。左下角/右下角的 **小翼 AI 助手** 悬浮球随时可唤起对话（见第四章）。

## 二、学生版使用说明

### 2.1 应急调度智能体（核心实训）

进入后是一个 **四步向导**，顶部显示流程进度（✓ 表示已提交），每一步完成并点击右侧 **「提交本步」** 后才能进入下一步；切换灾情案例后所有数据重置、从头走流程。

#### 第一步 · 案例与配送点

1. **加载案例**：从案例库选择灾情案例（含配送中心、受灾村庄、物资需求）。
2. **核对配送点**：地图上 `C` 为配送中心，数字圆点为需求点（鼠标悬停可看经纬度）。地图放大后每个点旁常显 **村庄名称标签**，方便核对。
3. **自定义配送点**（可选）：使用"地图选点"在地图上直接点击取坐标，或手动输入经纬度添加/调整配送中心与需求点。
4. **物资校准**（可选）：点"按灾情需求校准各点物资"，按各点灾情权重自动配比物资数量，确认后生效。
5. 完成后点 **「提交本步」**。

> 提示：需求点坐标已按真实村址校准；如发现点位异常可在本步调整。

#### 第二步 · 物资与选型

**① 物资分配（Module2）**

- 可"加载案例物资分配"一键带入，也可逐点手工分配；
- 为每个需求点选择物资类别与数量，页面顶部实时统计 **已分配 / 未分配** 点位，全部满足后才可提交。

**② 无人机选型（Module3）**

- 从机型库选择无人机型号与数量；
- 系统自动评估机型与物资的 **适配性**（载重、航程、冷链等），适配结果不满足时会有提示；
- 选好后点 **「提交本步」**。

#### 第三步 · 规划与诊断

本步含 4 个子页（顶部 tab 切换）：

**① 路径规划（Module4）** —— 核心

1. 选择 ACO 算法档位：**快速**（30 蚂蚁/50 迭代，课堂演示）/ **标准**（30/100）/ **精细**（80/200，精度优先），档位会记住你的选择；
2. 点"开始规划"，蚁群算法计算各无人机航次路线，地图上绘出彩色航线；
3. **手动调整配送顺序**（新功能）：在"路径汇总"表中，多村联飞航次可点 **「⇅ 调整」**，用 ↑↓ 交换村庄配送顺序，保存后系统按同一口径重算距离/时间/载重，地图与诊断同步刷新——可以用来验证"算法排得比你好还是不好"；
4. 改乱了点 **「↩ 回退算法结果」** 一键恢复原始方案。

**② 航线详情（Module9）**

- 查看每架无人机的逐段航路、起降时间与载重曲线，可按航次筛选。

**③ 方案诊断（Module5）**

- 点"规则诊断"或"AI 诊断"，从 **安全性 / 时效性 / 经济性 / 可行性** 四个维度给方案打分，输出风险警告与优化建议；
- 建议先诊断再进下一步，带着问题去辩论。

**④ 合规核验（Module13）**

- 对禁飞区、限高、续航等合规项 **先自判**，提交后规则引擎复核；
- 若不合规，可"回填建议参数"跳回路径规划重新生成。

完成后点 **「提交本步」**。

#### 第四步 · 辩论与优出

**① 反向质询（Module12）**

- 面向 AI 辩论会：输入你的方案陈述，选择质询维度（安全性/时效性/经济性/可行性/合规性）与置信度；
- AI 将从假设提出 → 验证分析 → 反驳交锋 → 重构优化四阶段与你来回辩论，扛住质询说明方案站得住。

**② 方案优出（Module6）**

- 点 **「生成报告」** 沉淀当前方案，支持 **下载 Word / 下载 PDF**；
- 在"历史方案"中对比多次规划结果，择优决策；
- 选中某份历史方案可 **派生重生成**（回填当时参数微调重跑）。

**③ 方案审阅（Module10）**

- 教师端页面：学生提交后，教师在此查看全班方案并给出评定（学生端可见提交状态）。

> 完成第四步提交，即完成一次完整实训闭环。

### 2.2 装箱评价智能体

用于应急装载训练的 AI 视觉评价：

1. 选择班级/学生，填写运输箱参数；
2. 按引导完成步骤；
3. 系统给出得分环、检查清单逐项判定与实时提示；

### 2.3 课程图谱

- **教学图谱**：以力导向图 / 径向树 / 层级树三种视图浏览课程知识结构，节点可拖拽、缩放；
- **项目详情**：查看各教学项目的学时、任务分解、技能与思政映射。

### 2.4 我的课程

- 浏览课程卡片，点进课程查看 **课件 / 资料** 两个分类；
- 支持在线 **预览**（PDF/图片/视频，其他格式请下载查看）与 **下载**；
- 上传与删除仅教师可用。

### 2.5 教学智评（学生参与）

- **任务4 · AI智能体子系统**：查看本组任务工单、摄像头画面，使用 AI 检查与得分环，接收灾情指令；
- **任务8 · 电子评量表**：演练结束后完成 **学生自评** 与 **同学互评**（安全/规划/团队/改进四个维度）；
- 教师大屏与热力图仅教师可见。

### 2.6 小翼 AI 助手

- 右下角 **悬浮球**：点击展开对话面板，内置快捷问题，支持最小化与全屏；
- **全屏对话页**：更大视野，支持语音输入，回答中会展示 AI 调用了哪些数据工具（过程透明）；
- 可以问："当前案例的最优距离是多少？""帮我看看方案有什么风险"等，小翼能读取平台数据回答。

## 三、教师版使用说明

### 3.1 教师与学生权限差异

| 功能               |    教师   |     学生    |
| ---------------- | :-----: | :-------: |
| 课件/资料 上传与删除      |    ✅    | ❌（可预览/下载） |
| 应急调度四步向导         |  ✅（可演示） |     ✅     |
| 方案审阅（Module10）   |    ✅    |    仅状态    |
| 教学智评 · AI教学分析    |    ✅    |     ❌     |
| 任务8 实时大屏 / 班级热力图 |    ✅    |     ❌     |
| 教学监控             |    ✅    |     ❌     |
| 系统管理（学生/课程数据）    |    ✅    |     ❌     |
| 电子评量表            | 教师/裁判评分 |   自评/互评   |

### 3.2 我的课程（课件管理）

1. 导航进入 **我的课程** → 右上角 **「上传课件」**；
2. 填写课程名，选择类型（课件/资料），选取文件（支持 PPT/Word/PDF/视频/图片/压缩包，单个不超过 50MB）；
3. 选错文件可在弹窗内点 **⊗ 移除** 重选；
4. 进入课程详情页可 **删除** 文件（二次确认）、按类型筛选；
5. 上课前建议：PPT 转 PDF 再上传，学生即可在线预览。

### 3.3 应急调度智能体（教师端）

教师可完整走一遍学生流程用于备课/演示，另有三个教师专属能力：

- **方案审阅（Module10）**：查看全班提交的方案（小组、姓名、距离/时长/点位），点开可视化比对，给出评定结论；
- **管理工具（导航条右侧收纳区）**：
  - 🗂 **信息管理**：案例库与无人机机型库的增删改、物资示例数据维护；
  - ⚙ **系统设置**：大模型配置等系统参数；
  - 🖼 **方案看板**：教学图片素材管理。
- **教学闸口**：向导每步需"提交本步"解锁下一步——可用于要求学生按节奏推进；切换案例自动重置进度。

### 3.4 教学智评

- **环节总览**：教学智评主页列出各教学环节卡片（时间、维度、统计），进行中的环节可"进入大屏"；
- **任务8 实时大屏**：演练现场投屏，实时展示各小组方案优化与模拟演练数据；
- **班级热力图**：按小组 × 维度展示全班得分分布，定位薄弱项；
- **电子评量表**：教师/裁判为各小组演练打分（学生端自评互评同屏汇总）；
- **AI 教学分析**：对环节生成 AI 学情分析（支持演示数据/真实方案双模式，网络异常自动降级内置点评，不中断课堂）；
- **任务7 评分 / 环节详情**：逐环节查看学生明细与成绩总览。

### 3.5 教学监控

教师专属页面，跟踪 **全班学生课前方案产出、合规核验质量、反向质询参与情况**，适合课前/课中快速点名谁没做、做到哪一步。

### 3.6 系统管理

- **学生管理**：批量导入学生名单（可下载 Excel 模板）、重置、刷新；
- **课程数据管理**：课程项目库的查看、导入、导出、删除（含知识图谱数据）。

## 四、常见问题（FAQ）

**Q1：向导里下一步点不进去？**
未提交当前步骤。完成该步要求后点右上角 **「提交本步」**；已提交的步骤可随时回去改（改后需重新提交）。

**Q2：手动调序后想恢复算法结果？**
路径汇总表上方点 **「↩ 回退算法结果」**，立即恢复本次 ACO 原始方案。

**Q3：课件点"预览"没反应/按钮置灰？**
部分文件暂不支持在线浏览，若无法直接打开，请下载查看；

**Q4：AI 点评/小翼不回复？**
大模型接口有时限流，系统会 **自动切换备用模型**；连续失败时点评功能会降级为内置规则点评，不中断课堂。稍等片刻重试即可。

**Q5：切换案例后数据还在？**
切换案例会自动清空物资分配、规划结果与提交进度，请确认当前案例无误后再开始。

**Q6：实训任务 / 学习资源显示"开发中"？**
两个模块在规划中，当前教学内容集中在"应急调度"智能体与"教学智评"。
